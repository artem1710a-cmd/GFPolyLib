GFPolyLib 2.0 — динамическая библиотека операций над многочленами в поле Галуа GF(q), q = p^k
=======================================================================================

Автор: Машир А.Ю., гр. 3431, ГУАП, 2026. Руководитель: Фомичева С.Г.

СОСТАВ
  GFPolyLib\          исходный код динамической библиотеки GFPolyLib.dll (C#, .NET 8)
  GFPolyLib.Tests\    модульные тесты (xUnit)
  GFPolyApp\          демонстрационное приложение (Windows Forms) с хранилищем SQLite
  GFPolyCli\          консольная утилита: пакетные вычисления и замеры производительности
  samples\            примеры файлов исходных данных *.gfp
  GFPolyLib.sln       решение Visual Studio 2022

ВОЗМОЖНОСТИ БИБЛИОТЕКИ
  - простые поля GF(p) с p произвольного размера (до 8192 бит) и расширения GF(p^k), k <= 256;
  - проверка простоты p (Миллер — Рабин), неприводимости модуля расширения (Бен-Ор),
    автоматический подбор неприводимого многочлена;
  - сложение, вычитание, умножение (школьное, Карацубы с распараллеливанием),
    деление с остатком («уголком», Ньютона), вычисление значения (схема Горнера);
  - коды ошибок вместо аварийного завершения, отмена длительных операций.

СБОРКА И ЗАПУСК (нужен .NET SDK 8.0)
  dotnet build GFPolyLib.sln -c Release
  dotnet test  GFPolyLib.Tests -c Release
  dotnet run --project GFPolyApp -c Release

  Готовая к установке версия (одна папка, без установки .NET — self-contained):
  dotnet publish GFPolyApp -c Release -r win-x64 --self-contained true -o publish

ИСПОЛЬЗОВАНИЕ БИБЛИОТЕКИ В СВОЕЙ ПРОГРАММЕ
  using GFPolyLib;
  var f = GaloisField.Create("7");               // или Create("2", 8) для GF(2^8)
  var a = f.Parse("3x^4 + 5x^3 + x + 6");
  var b = f.Parse("2 4 1");                      // 2x^2 + 4x + 1
  var (q, r) = a.DivRem(b);                      // q = 5x^2 + 3x + 2, r = 4x + 4
  Console.WriteLine(a.Evaluate("2"));            // 5

ХРАНИЛИЩЕ
  База данных SQLite: %LOCALAPPDATA%\GFPolyLib\gfpoly.db (создаётся автоматически).
