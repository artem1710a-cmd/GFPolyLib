РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ GFPolyLib Demo 2.0

1. НАЗНАЧЕНИЕ
Программа демонстрирует работу динамической библиотеки GFPolyLib.dll, выполняющей
арифметические операции над многочленами с коэффициентами из конечного поля
(поля Галуа) GF(q), q = p^k: сложение, вычитание, умножение, деление с остатком
и вычисление значения многочлена в точке. Результаты и исходные данные
сохраняются в реляционном хранилище (файл базы данных SQLite).

2. ЗАДАНИЕ ПОЛЯ
- «Характеристика p» — простое число. Допускаются выражения: 7, 65537, 2^61-1,
  2^127-1, 10^9+7. Размер p ограничен 8192 битами.
- «Степень расширения k» — от 1 до 256. При k = 1 поле простое, элементы — числа
  от 0 до p − 1. При k > 1 элементы поля записываются как многочлены от
  порождающего элемента a степени меньше k, например a^2 + 1.
- «Порождающий f(x)» — неприводимый многочлен степени k (только при k > 1).
  Если поле оставить пустым, многочлен будет подобран автоматически
  (для GF(2^8) — x^8 + x^4 + x^3 + x + 1, как в стандарте AES).
Нажмите «Создать поле». Составное p или приводимый f(x) будут отклонены
с пояснением причины.

3. ВВОД МНОГОЧЛЕНОВ
Многочлены A(x) и B(x) вводятся в одной из двух форм:
- алгебраическая: 3x^4 + 5x^3 - x + 6 (знак умножения * можно ставить или нет);
- список коэффициентов от старшего к младшему через пробел или запятую:
  3 5 0 -1 6.
Коэффициенты поля-расширения записываются в скобках: (a^2 + 1)x^3 + (a)x + 1.
Отрицательные коэффициенты приводятся по модулю p. Коэффициент, по модулю
не меньший p, считается ошибкой. Недопустимые символы не вводятся, а ошибка
записи отмечается красным значком рядом с полем (наведите на него курсор,
чтобы прочитать пояснение).
Кнопки «Случайный A/B» заполняют поле многочленом заданной степени
со случайными коэффициентами — так удобно проверять работу на больших данных.
«Точка c» — элемент поля, в котором вычисляется значение A(c).

4. ВЫПОЛНЕНИЕ ОПЕРАЦИЙ
Кнопки A + B, A − B, A × B, A ÷ B, A(c) становятся доступны, когда создано поле
и заданы нужные операнды. Алгоритмы умножения и деления выбираются в списках;
в режиме «Автоматически» библиотека сама выбирает алгоритм по размеру данных.
Длительную операцию можно прервать кнопкой «Прервать». Результаты выводятся
в нижнее окно; длинные многочлены показываются сокращённо, полностью они
сохраняются в файл (Файл → Сохранить результаты).

5. ФАЙЛЫ
Файл → Открыть исходные данные (Ctrl+O) загружает файл *.gfp:
    # комментарий
    p = 7
    k = 1
    modulus =
    A = 3x^4 + 5x^3 + x + 6
    B = 2 4 1
    c = 2
Примеры находятся в папке samples. Файл → Сохранить исходные данные (Ctrl+S)
записывает текущие данные в том же формате. Файл → Сохранить результаты
(Ctrl+Shift+S) сохраняет отчёт о всех выполненных операциях.

6. ПЕЧАТЬ
Файл → Предварительный просмотр и Файл → Печать (Ctrl+P) выводят отчёт
о выполненных операциях на принтер. Перед печатью большого отчёта программа
сообщает ожидаемое число страниц.

7. ХРАНИЛИЩЕ
При включённом флажке «Записывать операции в журнал хранилища» каждая
операция сохраняется в базе данных вместе с операндами и результатом.
Вкладка «Хранилище» показывает сохранённые многочлены и журнал операций:
многочлен можно загрузить в A или B, операцию из журнала — повторить.
Хранилище → Сохранить многочлен A/B сохраняет многочлен под названием.
Одинаковые многочлены хранятся в одном экземпляре. Файл базы данных:
%LOCALAPPDATA%\GFPolyLib\gfpoly.db.

8. ПРОИЗВОДИТЕЛЬНОСТЬ
Вкладка «Производительность» измеряет время умножения (школьный алгоритм
и алгоритм Карацубы) или деления («уголком» и методом Ньютона) для ряда
степеней многочленов в текущем поле и строит график. Результаты замеров
сохраняются в хранилище.

9. СООБЩЕНИЯ ОБ ОШИБКАХ
- «характеристика поля должна быть простым числом» — введите простое p;
- «порождающий многочлен приводим» — задайте другой f(x) или оставьте поле пустым;
- «коэффициент не принадлежит полю» — коэффициент больше или равен p;
- «деление на нулевой многочлен» — B(x) = 0;
- «недостаточно оперативной памяти» — уменьшите степень многочленов.

10. СИСТЕМНЫЕ ТРЕБОВАНИЯ
Windows 10/11 x64, .NET Desktop Runtime 8.0, 100 МБ свободного места на диске,
не менее 4 ГБ оперативной памяти (для многочленов степени выше 10^6 — 8 ГБ).
